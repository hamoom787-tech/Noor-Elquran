# 🎥 مولد فيديوهات القرآن الكريم - Quran Reels Video Generator

تطبيق ويب محلي لتوليد فيديوهات قصيرة (ريلز) لآيات القرآن الكريم مع خلفية طبيعية وصوت التلاوة والنص العربي.

## ✨ المميزات

- 📖 اختيار القارئ من قائمة واسعة من القراء
- 🕌 اختيار أي سورة من القرآن الكريم
- 📝 اختيار نطاق الآيات (آية واحدة أو عدة آيات)
- 🎬 توليد فيديو احترافي بخلفية طبيعية
- 🎵 صوت عالي الجودة للتلاوة
- ✍️ نص عربي واضح ومنسق
- 📥 تحميل الفيديو النهائي بسهولة
- 🎨 واجهة مستخدم جميلة وعصرية

## 📋 المتطلبات

### 1. Python 3.8 أو أحدث
تحقق من تثبيت Python:
```bash
python --version
```

### 2. FFmpeg
- **Windows**: قم بتحميل FFmpeg من [الموقع الرسمي](https://ffmpeg.org/download.html)
  - استخرج الملفات وأضف مجلد `bin` إلى متغيرات البيئة PATH
  - أو حدد المسار الكامل في ملف `config.py`

### 3. ImageMagick (اختياري - للتحكم المتقدم في النصوص)
- **Windows**: قم بتحميل ImageMagick من [الموقع الرسمي](https://imagemagick.org/script/download.php)

## 🚀 التثبيت والإعداد

### 1. تثبيت المكتبات المطلوبة
```bash
pip install -r requirements.txt
```

### 2. إضافة فيديوهات الخلفية
- ضع ملفات الفيديو (بصيغة .mp4) في مجلد `vision/`
- يمكنك استخدام فيديوهات لمناظر طبيعية، سماء، بحر، إلخ.
- الأبعاد المثالية: 1080x1920 (عمودي - Vertical)

### 3. تكوين المسارات (اختياري)
إذا لم يكن FFmpeg و ImageMagick في PATH، قم بتحديث المسارات في `config.py`:

```python
FFMPEG_PATH = r"C:\path\to\ffmpeg.exe"
IMAGEMAGICK_PATH = r"C:\path\to\magick.exe"
```

## ▶️ التشغيل

### 1. تشغيل السيرفر
```bash
python main.py
```

### 2. فتح المتصفح
افتح المتصفح على العنوان التالي:
```
http://localhost:5000
```

## 📖 طريقة الاستخدام

1. **اختر القارئ**: من القائمة المنسدلة
2. **اختر السورة**: من قائمة السور
3. **حدد نطاق الآيات**: أدخل رقم الآية الأولى والأخيرة
4. **انقر على "إنشاء الفيديو"**: انتظر حتى يكتمل التوليد
5. **معاينة وتحميل**: شاهد الفيديو وحمله من الواجهة

## 🔧 الإعدادات المتقدمة

يمكنك تخصيص الإعدادات في ملف `config.py`:

- **VIDEO_WIDTH / VIDEO_HEIGHT**: أبعاد الفيديو
- **VIDEO_FPS**: معدل الإطارات
- **TEXT_FONT_SIZE**: حجم الخط
- **TEXT_COLOR**: لون النص
- **TEXT_STROKE_COLOR**: لون حدود النص
- **VERSE_DISPLAY_DURATION**: مدة عرض الآية (بالثواني)

## ⚠️ ملاحظات مهمة

1. تأكد من وجود ملفات فيديو في مجلد `vision/` قبل التوليد
2. الاتصال بالإنترنت مطلوب لأول مرة لجلب البيانات
3. البيانات تُخزن محلياً بعد أول جلب للاستخدام السريع
4. عملية التوليد قد تستغرق بضع دقائق حسب عدد الآيات
