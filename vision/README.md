# Instructions for Background Videos

## What You Need

Place your background video files (.mp4) in this folder.

## Recommendations

1. **Format**: MP4 (H.264)
2. **Resolution**: 1080x1920 (vertical - Reels/Stories format)
   - Or any 9:16 aspect ratio
3. **Duration**: At least 10-30 seconds
4. **Content**: 
   - Nature scenes (mountains, ocean, sky, forest)
   - Abstract backgrounds
   - Peaceful scenery
   - Avoid distracting or busy backgrounds

## Free Video Sources

You can download free background videos from:
- Pixabay: https://pixabay.com/videos/
- Videvo: https://www.videvo.net/

Search for: "nature vertical", "sky vertical", "peaceful background"

## Example Filenames

- nature1.mp4
- ocean.mp4
- sky_sunset.mp4
- mountains.mp4

The application will randomly select one of these videos as background.
